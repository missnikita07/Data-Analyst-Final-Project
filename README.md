# Customer Churn Analysis

## Project Overview

Customer Churn Analysis is an end-to-end data analytics project focused on
understanding customer churn behavior and identifying patterns that can
support customer retention strategies.

The project combines data cleaning, SQL analysis, Python-based exploratory
data analysis, Excel analysis, and an interactive Power BI dashboard.

## Objectives

- Analyze customer churn behavior
- Identify patterns associated with customer churn
- Understand customer segments with different churn behavior
- Perform data cleaning and validation
- Analyze the dataset using SQL and Python
- Build an interactive Power BI dashboard
- Generate business recommendations for customer retention

## Dataset

The dataset contains 1,000 customer records and includes information such as:

- Customer ID
- Age
- Gender
- Tenure
- Balance
- Number of Products
- Credit Card Ownership
- Active Membership
- Estimated Salary
- Churn

## Key Results

- Total Customers: 1,000
- Churned Customers: 17
- Active Customers: 983
- Overall Churn Rate: 1.70%

The analysis identified differences in observed churn patterns across
customer characteristics such as product usage, tenure, gender,
credit card ownership, active membership, and age.

## Business Recommendations

1. Monitor customers with multiple products, particularly customers with
   four products where the highest observed churn rate was identified.

2. Focus on customer engagement because customer activity can be an
   important indicator of retention.

3. Monitor customers during early tenure and provide appropriate
   onboarding and engagement support.

4. Develop segment-based retention strategies based on customer
   characteristics.

5. Use regular churn monitoring to identify potentially vulnerable
   customer segments.

6. Collect additional historical churn observations to improve the
   reliability of churn analysis.
